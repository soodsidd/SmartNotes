# SN-301 photo evidence

- `01-side-by-side.png` compares the Settings → Server tab (running) with fork photo #1. `01-stopped-side-by-side.png` shows the same tab after a real Stop, with Start enabled while the app server is down. Uncropped dialog captures: `01-server-tab-desktop.png`, `02-server-stopped-desktop.png`, `03-server-log-desktop.png` (log expanded), `04-server-tab-mobile.png` (430 px).
- `seed-fixture.mjs` writes an isolated worktree vault and state. `capture.mjs` drives Chromium against a worktree-local `gateway-start.js` supervisor and records checks in `console.txt`. `compare.py` builds the labelled comparisons from the source photos in the primary repo.
- All 16 browser checks pass against the live supervisor (no mocks). They cover tab order, the spec §1 subtitle, row order, Build matching `/api/version`, Start disabled while running, a real Stop that closes the app port, Start while stopped (new PID), Restart (new PID), the log tail with exit and startup lines, mobile has no horizontal overflow, and zero console errors while the server was up.
- Values differ from the photo by design: they are live (port 3311, real PID/uptime/BUILD_ID). Assumptions where the photo is silent: the Process value is monospace (as it appears in the photo; the spec names only Address and Build); `Stopping…` is shown during Stop; when no supervisor answers, the buttons are disabled with a muted explanatory note.
- Preview: `POST /api/preview/start` accepted the supervised command, but the sidecar marked it `failed` ("port already owned by another process"). Its ownership check needs `wmic` to walk the process tree (AV-277). Without it, only the root `cmd` PID counts, and the listener is the supervisor's child. The capture therefore runs against an unregistered worktree-local supervisor on port 3311 (control 3319), with `SMART_NOTES_VAULT`/`SMART_NOTES_STATE_DIR` pointing at `.e2e-vault-sn301`/`.e2e-state-sn301`. The AV sidecar (:8787) and production (:3002) were untouched.
